# HiBrands logo kit

The mark is a speech bubble that says "Hi". It stands for what HiBrands is about:
you talk directly to the people who do the work.

## Which file to use

| Need | File |
|---|---|
| Website, documents, presentations (light background) | `svg/hibrands-logo-color.svg` |
| On cobalt, dark or photo backgrounds | `svg/hibrands-logo-reverse.svg` |
| Printing in one colour, stamps, invoices | `svg/hibrands-logo-black.svg` / `-white.svg` |
| Square or narrow spaces | `svg/hibrands-logo-stacked-*.svg` |
| App icon, avatar, small spaces | `svg/hibrands-icon-*.svg` |
| Name only, no icon | `svg/hibrands-wordmark-*.svg` |
| Instagram / LinkedIn / WhatsApp profile picture | `social/profile-picture-*.png` |
| Link previews (website share image) | `social/link-share-1200x630.png` |
| Website tab icon | `favicon/` |
| Print shop / designer | `pdf/` |

**SVG** is the master format. It scales to any size and the text is already turned into
shapes, so it looks right even on computers without the font. Use **PNG** (transparent
background) where SVG isn't accepted, such as Word, Canva uploads or WhatsApp.
`png/` holds large versions; `png/small/` holds lighter ones for email signatures and documents.

## Colours

| Name | Hex | Use |
|---|---|---|
| Ink | `#18213D` | Text, one-colour logo |
| Cobalt | `#3050F0` | "Hi", buttons, links |
| Marigold | `#FFC83D` | The bubble, highlights |
| Mint | `#C6EEDB` | Soft backgrounds, "done" states |
| Sky | `#EEF3FF` | Page background |

## Fonts

- Headings and logo: **Bricolage Grotesque** (ExtraBold, 800)
- Body text: **Geist**

Both are free (SIL Open Font License) from Google Fonts / fontsource.

## Rules

- Keep clear space around the logo at least the height of the "H".
- Don't stretch, rotate, recolour or add effects (shadows, outlines, gradients).
- Don't put the colour logo on busy photos. Use the white version on a dark overlay instead.
- Smallest size: logo 100 px wide on screen (25 mm in print); icon 16 px.
